# 01 全部法条版本入库 + 时效元数据（建库·导入这一环）

> 在 [00 全景图](00-系统怎么跑起来的.md) 的位置：**建库流程第一步**（`ingest_npc.py`）。
> 它决定了 `data/docs/` 里到底躺着什么，后面切块、建索引、出评测题全都吃它的输出。

## 1. 它在系统里是什么

- **上游**：官网抓下来的 docx 原件 + 每部法的 `metadata.jsonl`（含 `status_code` / `effective_date` / 版本号 `bbbs`）。
- **它做的**：把每部法的**每个历史版本**渲染成一个独立的 `.md`，正文外面套一层"时效 front-matter"。
- **下游**：`build_index.py` 读这些 `.md` 切块建索引；`build_eval_set.py` 读 metadata 出 D/E 类题。
- **产物**：`data/docs/{statute,interpretation,faq}/*.md`，共 **2951 篇**。

## 2. 数据长什么样（具体，不是抽象描述）

"保留全部版本"落到实处 = **同名法不去重，每个版本一个文件**。文件名 = `{标题[:70]}_{bbbs}.md`，
`bbbs` 是官网版本号（全局唯一）。例：国防动员法在库里有**两个**文件——

```
中华人民共和国国防动员法_2c909fdd678bf17901678bf70aee057d.md   → status_code: 3, effective_date: 2010-07-01（现行有效）
中华人民共和国国防动员法_7d951fed0e964a509d223ebd47af0f5a.md   → status_code: 4, effective_date: 2026-10-01（尚未生效）
```

每个 `.md` 顶部的 front-matter 关键字段：

```yaml
---
title: "中华人民共和国国防动员法"
version: "7d951fed0e964a509d223ebd47af0f5a"   # = bbbs，版本唯一标识
status_code: 4                                 # 1废止 / 2已修订 / 3现行有效 / 4未生效 / null未标注
status_label: "尚未生效"
effective_date: "2026-10-01"
law_nature: "法律"                             # 位阶：法律 / 行政法规 / 司法解释
source_category: "法律"
---
```

## 3. 代码怎么做的（`scripts/ingest_npc.py`）

- `load_metadata(cat)`：读 `data/raw/npc/{法律,行政法规,司法解释}/metadata.jsonl`。
- `assert_metadata_fields()`：**缺 `status_code` 键直接报错，不给默认值兜底**。
  （旧项目正是把字段名写成 `status` 而非 `status_code`，2466 条时效元数据全落空、front-matter 被硬编成 `current`，
  整个"时效治理"能力变空话——所以这里宁可崩也不兜底。）
- `slugify(title, bbbs)`：文件名用**完整 bbbs**。因为 bbbs 前 8 位只有 70 个唯一值（会静默覆盖），
  只有全量 bbbs 才 2466/2466 唯一。
- `render_statute()`：docx 段落 → Markdown，识别 编/章/节/条，**条渲染成 `**第X条** 正文`**（切块靠这个识别，见 11）。
- `build_front_matter()`：把 `status_code` / `effective_date` / `version` / `law_nature` 写进 `.md` 头部。
- 同名多版本 → 落成多个文件；若 slug 撞车**直接 raise**（不允许静默覆盖，旧项目评测集就被覆盖过三次）。

## 4. 为什么必须这么造（工程约束）

- **下游 D 类评测要判"返回的是哪一版"** → 每个版本必须是独立文件 / 独立节点、各带自己的 `status_code`；
  只留最新版，就没有"版本"可判了（见 04、11）。
- **currency 时效重排要读节点的 `status_code` 加权** → 元数据必须从 front-matter 一路带进 Qdrant payload
  （这一步在 `build_index.py` 切块时完成，见 00 图 [1]）。
- **字段断言不能省**：时效是本项目唯一的差异化数据，字段名错一个 = 能力静默失效，所以用断言把错误挡在入库前。

## 5. 怎么验证它对

- `python scripts/verify_version_gt.py`：应输出 2466 条、**377 个多版本标题、431 个额外版本**；
  且 `status_code=4` 的 9 条全部满足 `effective_date > 今天`。
- 建库后看 `reports/build_index_report.json` 的 `nodes_with_status_code` 应 = 节点总数（实测 **88681/88681**，100% 覆盖）。
- 手工抽查：任一多版本标题（如国防动员法），`data/docs/statute/` 下应有 2 个 `.md`，`status_code` 分别是 3 和 4。
