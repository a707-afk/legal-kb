# 04 评测集反同源 + 拒答双侧（评测这一层）

> 在 [00 全景图](00-系统怎么跑起来的.md) 的位置：不在主数据流上，是**离线评测层**——
> `build_eval_set.py` 出题、`run_eval.py` 判分。它决定了"系统好不好"这句话可不可信。

## 1. 它在系统里是什么

- **产物**：`eval/sets/v1.jsonl`（210 题）+ `v1.manifest.json`（指纹 + 计数）。
- **两个脚本**：`build_eval_set.py`（生成，可复现）+ `run_eval.py`（跑检索 + 判分 + 出报告）。
- **要解决的核心问题**：如果题目和语料同源（答案就在库里），指标会虚高到没有意义。

## 2. 数据长什么样

每题一行 JSON：
```json
{"id":"D-0123","category":"D","difficulty":"version_time_travel","same_source_level":"弱",
 "question":"在 2015 年时，《工会法》适用的是哪一版？",
 "gt":{"probe_year":2015,"expected_bbbs":"2c909fdd...","expected_file":"data/docs/statute/...md"},
 "judge":{"type":"version_effective_at_year","year":2015},"provenance":"auto:multi_version_time_travel"}
```
manifest 记：`git_commit` + `script_sha256` + `content_sha256` + `seed` + 各类 n + `same_source_level` + `judge_types`。

## 3. 代码怎么做的

**`build_eval_set.py`（出题）**：
- 六类各有生成器：A 从语料抽条文；D 从多版本标题出（现行/列版本/时间旅行三梯度）；
  E 从 status_code=4 + 位阶对出；F 语料外 + status_code 缺失；B/C 是**手写种子**。
- **B/C 手写种子必须过"原文校验"**：种子写的期望法名 + 关键词，脚本回语料里验证
  "该法存在且关键词命中正文"，不命中就**丢弃并报告**（`b_dropped`/`c_dropped`）。
  （实测这道校验抓出我 4 处凭记忆配错的跨法条对。）
- **冻结护栏**：`v1.jsonl` 一旦存在，再跑**拒绝就地覆盖**（要 `--version v2` 或 `--force`）。
- **可复现**：固定 `seed` → 同 commit 重跑逐字节一致。

**`run_eval.py`（判分）**：`judge(item, retrieved, gate_passed)` 按 `judge.type` 分派——
全部基于**检索结果**判（不跑 LLM 生成，因此快、可复现、零 API 成本）；
只有 F 类 `should_disclaim`（要判"生成时是否老实说不知道时效"）标 `generation_required` 跳过。

## 4. 为什么必须这么造（工程约束）

- **反同源**：A 类金标=语料原文、查询含法名+条号 → 判"文件命中"会退化成标题匹配、指标虚高。
  所以每题标 `same_source_level`（强/中/弱），A 类明确**只当回归基线、不当能力证据**。
- **拒答双侧 + dev/test 分离**：用同一集标定阈值又报准确率 = 泄漏。所以 F 类拆 `dev`/`test`，
  且判分同时看"该拒的拒了没"和"不该拒的误拒了没"。
- **冻结不覆盖**：旧项目评测集同名被覆盖三次 → 结果不可复现。所以脚本层面禁止就地覆盖。

## 5. 怎么验证它对

- `python scripts/build_eval_set.py --dry-run`：看六类各能生成多少（A60/B40/C20/D40/E20/F30）。
- 再跑一次正式生成：应被**冻结护栏拒绝**（证明不可就地覆盖）。
- `python scripts/run_eval.py --config baseline --limit 5`：小样冒烟，确认判分链路通。
- D/E 类 GT 手算核对：时间旅行 probe_year→取 effective_date≤该年末的最新版；国防动员法未生效 eff=2026-10-01。

## 6. 代码位置

- `scripts/build_eval_set.py`（六类生成器 + 原文校验 + 冻结护栏）
- `scripts/run_eval.py`（`judge()` 十种判分 + 过期法条率 + `--both` 对照）
